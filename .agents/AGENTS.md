# Reglas del Agente (RumboLatam)

Aquí puedes agregar reglas, instrucciones y pautas de estilo que el agente de IA debe seguir para este proyecto.

## Gestión de Paquetes
- **CRÍTICO**: Usar única y exclusivamente `pnpm` para la instalación de dependencias y ejecución de scripts. JAMÁS utilizar `npm` o `yarn`.

## Desarrollo Web

- Las variables deben tener formato camelCase.
- Los nombres de componentes deben tener formato PascalCase.
- Los nombres de funciones deben tener formato camelCase.
- Las funciones deben ser pequeñas y deben tener un bloque de comentario indicando su propósito.
- Los nombres de clases deben tener formato PascalCase.


## React

- Los componentes deben ser funciones de flecha.
- Las funciones deben ser pequeñas y deben tener un bloque de comentario indicando su propósito.

## Modularización de código
- El codigo debe ser lo más modular posible
